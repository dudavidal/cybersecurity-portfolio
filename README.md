# 👩‍💻 Portfólio de Cibersegurança 

 Sou estudante de Computação e estou iniciando minha jornada na área de cibersegurança.

Este portfólio foi criado com o objetivo de documentar meu processo de aprendizado e acompanhar minha evolução na área. Comecei meus estudos a partir dos fundamentos, principalmente redes de computadores, e estou avançando por meio de prática com laboratórios e desafios reais.

Este portfólio representa minha evolução na área de cibersegurança, desde os primeiros passos até níveis mais avançados.


## 🎯 Objetivo

* Documentar write-ups de máquinas e desafios
* Demonstrar meu raciocínio técnico e processo de exploração
* Acompanhar minha evolução em cibersegurança

## 🧠 Atualmente estudando

* Fundamentos de redes
* Enumeração de serviços
* Exploração de vulnerabilidades web
* Escalada de privilégios em Linux
